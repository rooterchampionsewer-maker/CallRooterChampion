# CallRooterChampion — Project Notes

A standalone **landing page** for Rooter Champion's **$55 drain cleaning + free camera inspection**
special, intended for the **callrooterchampion** domain. Derived from rooterchampion.net but a
separate project / git repo.

## What's built (index.html, single page — redesigned Oct 2026)
Layout modeled on plumbinggroupservices.com.au; see CLAUDE.md "Don't Look AI-Made" rules.
- **Header** — logo + "Plumbing · Drains · Sewer" label + green call button.
- **Hero** — dark photo background; "Plumbers in …" line; stacked icon headline
  ($55 Drain Cleaning. / Free Camera Inspection. / Same-Day Service.); green check list;
  **offer card** (rc-navy + faint blue grid, $55 badge on top, centered text, green pill call button).
- **Services** — 6 rounded gray cards with inset photo + overlapping white panel, "Call about this ›".
- **Call band** — full-width green, uppercase heading + dark call button.
- **Reviews** — 4 white cards on light blue (real reviews from rooterchampion.net).
- **Area** — La Habra shop map (city pages swap in local drain issues + city map).
- **Footer** + **mobile sticky call bar**.
- Photos: compressed copies in `brand_assets/web/` (originals untouched).

## City landing pages (Google Ads location campaigns)
- Full list of pages + URLs for Google Ads: see `LANDING-PAGES.md` (auto-generated by the build).
- Live at `/la-habra/`, `/fullerton/`, `/la-mirada/`, `/whittier/` — root `index.html` stays the main LA & OC page.
- **Generated** — never hand-edit the city folders. City copy lives in `cities.mjs`; design comes from
  root `index.html`. After changing either, run `node build-cities.mjs`.
- Each page: city in title/H1/meta/schema, local section (drain issues, neighborhoods, ZIPs, real review
  from that city), `noindex` (rooterchampion.net owns organic city rankings).
- Call tracking: same Google forwarding-number swap as root; calls report per campaign in Google Ads.
  GA4 `phone_call_click` events carry a `city` param.
- Deploy: include the four city folders in the upload alongside index.html.

## Local workflow
1. `npm install`  (one time — installs puppeteer for screenshots)
2. `node serve.mjs`  → preview at http://localhost:3001
3. `node screenshot.mjs http://localhost:3001 label`  → saves to ./temporary screenshots/
